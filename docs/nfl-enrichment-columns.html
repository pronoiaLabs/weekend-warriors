What each table keeps, and what comes over

Table by table: the BDL base (what we already use, always the left side of the join), then exactly which columns nflverse and Sleeper bring over to enrich the row.

BDL — the base row + nflverse enrichment + Sleeper enrichment
Naming convention for the new schemas. The schema carries the role, so physical tables drop the dim_/fact_ prefix and every name is at least two words: NFL_PROD_DB.DIM.PLAYER_PROFILE, NFL_PROD_DB.FACTS.PLAY_LOG. dbt model names do not change — a generate_alias_name macro strips the prefix by folder, plus a small override map (dim_player → PLAYER_PROFILE, dim_team → TEAM_PROFILE, dim_game → GAME_SCHEDULE, dim_date → CALENDAR_DATE, dim_stadium → STADIUM_PROFILE, fact_play → PLAY_LOG, fact_trade → TRADE_ASSET) — so every ref(), semantic view and APP mart compiles untouched; only the relation names change. Section headers below show the physical name; each grain line names the dbt model. Prep models keep their stg_nfl__* names.

Asymmetries the mapping documents (measured, both directions):
  • nflverse-only: extra-point kicks (3,876 XP_KICK plays) have no BDL play type at all — BDL's play stream simply omits PATs. Unmatchable by design; XP stats still arrive via the box-score path on fact_player_game_special.
  • nflverse-only vocabulary: kneels (1,343) and spikes (224) are distinct types there, buried inside BDL's Rush and Pass Incompletion — which is why the mapping allows run or qb_kneel / pass or qb_spike.
  • BDL-only: ≈27k administrative rows (official timeouts alone are 13,904) mostly don't exist as nflverse plays. is_matchable keeps them out of the match denominator.
  • BDL-only coverage: preseason plays — nflverse pbp has no preseason, and bridge_game_ids already carries NULL for those games. Whole preseason games sit outside the match by construction.
  • nflverse carries a second, league-feed vocabulary (play_type_nfl: SACK, INTERCEPTION, PAT2, END_QUARTER…) that is closer to BDL's outcome framing — the flag checks lean on it where the analytics vocabulary is too coarse.

The trial-match queries behind these numbers
Tier 1 — strict match on all five keys
WITH bg AS (
  SELECT game_key, nflverse_game_id FROM BRIDGE_GAME_IDS
  WHERE nflverse_game_id IS NOT NULL AND is_nflverse_observed
),
f AS (
  SELECT p.play_key, bg.nflverse_game_id, p.period, p.clock_seconds_remaining,
         p.start_down, p.start_distance, p.start_yards_to_endzone
  FROM FACT_PLAY p
  JOIN bg ON bg.game_key = p.game_key
  JOIN DIM_PLAY_TYPE d ON d.play_type_key = p.play_type_key
  WHERE d.play_category <> 'Administrative'
),
n AS (
  SELECT game_id, qtr, quarter_seconds_remaining, down, ydstogo, yardline_100
  FROM NFL_PROD_DB.RAW.NFLVERSE_PBP
  WHERE play_type_nfl NOT IN ('END_QUARTER','END_GAME','GAME_START','COMMENT','TIMEOUT')
)
SELECT COUNT(*)                        AS matchable_rows,
       SUM(IFF(m.cnt = 1, 1, 0))       AS matched_unique,
       SUM(IFF(m.cnt > 1, 1, 0))       AS matched_ambiguous,
       SUM(IFF(m.cnt IS NULL, 1, 0))   AS unmatched
FROM f
LEFT JOIN (
  SELECT f2.play_key, COUNT(*) AS cnt
  FROM f f2
  JOIN n ON n.game_id = f2.nflverse_game_id
        AND n.qtr = f2.period
        AND n.quarter_seconds_remaining = f2.clock_seconds_remaining
        AND COALESCE(n.down, 0)         = COALESCE(f2.start_down, 0)
        AND COALESCE(n.ydstogo, 0)      = COALESCE(f2.start_distance, 0)
        AND COALESCE(n.yardline_100,-1) = COALESCE(f2.start_yards_to_endzone, -1)
  GROUP BY 1

Measured in dev: the bye derivation is exact — trial-derived from dim_game's regular-season slate, every season yields precisely 32 byes, one per team, weeks 5–14, with zero anomalies and every bye landing on an existing fact_team_season row. Because dim_game holds the full slate including future games, the upcoming season's byes are already derivable before a snap is played — useful for planning views, not just history.

The bye-week derivation query behind these numbers
Derive byes as the missing week per team-season, then validate
WITH tg AS (
  SELECT season, week, home_team_key AS team_key FROM DIM_GAME WHERE season_type = 2
  UNION
  SELECT season, week, away_team_key FROM DIM_GAME WHERE season_type = 2
),
allw  AS (SELECT DISTINCT season, week FROM tg),
teams AS (SELECT DISTINCT season, team_key FROM tg),
byes AS (
  SELECT t.season, t.team_key, w.week AS bye_week
  FROM teams t
  JOIN allw w ON w.season = t.season
  LEFT JOIN tg ON tg.season = t.season AND tg.team_key = t.team_key AND tg.week = w.week
  WHERE tg.team_key IS NULL
)
SELECT b.season,
       COUNT(*)                                AS bye_rows,        -- expect 32
       COUNT(DISTINCT b.team_key)              AS teams_with_bye,  -- expect 32
       MIN(b.bye_week)                         AS earliest_bye,
       MAX(b.bye_week)                         AS latest_bye,
       SUM(IFF(f.team_season_key IS NULL,1,0)) AS byes_without_fact_row  -- expect 0
FROM byes b
LEFT JOIN FACT_TEAM_SEASON f ON f.team_key = b.team_key AND f.season = b.season
GROUP BY 1 ORDER BY 1;

-- anomaly check: any team-season with more or fewer than one bye (returned zero rows)
SELECT season, team_key, COUNT(*) FROM byes GROUP BY 1, 2 HAVING COUNT(*) <> 1;
