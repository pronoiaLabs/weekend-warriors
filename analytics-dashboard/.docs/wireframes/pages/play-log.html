concept: session-state write-back — the agent's tool calls edit the
         same state the chips edit
routes:  POST /api/nfl/agent/session   (agent writes filters)
         GET  /api/nfl/agent/session/{id}  (page hydrates on load)
table:   app_api.agent_sessions (session_id, page, filters jsonb,
         saved_views jsonb, updated_at)
loop:    agent → UPDATE session → page re-queries /api/nfl/plays with
         session filters → chips, highlights and folds re-render
