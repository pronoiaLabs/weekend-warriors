The app, screen by screen

Nine wireframes for the redesign, built on the journey from the screens plan: catch up on the league, then go fishing for players — game lane or player lane — and dig in at play grain. Every page uses the app's real Glass Prism theme (plus the new light mode — toggle in the topbar), real player headshots and team branding from the warehouse, and annotates each zone with the APP mart and API route feeding it (look for the dashed data expanders).

How to read these

conventions

Sample context is consistent across all nine pages — season 2025, week 8, DraftKings, marquee game BUF @ KC, focus player Ja'Marr Chase, focus team Detroit — so cross-page links land where you expect. Headshots and team logos are live CDN assets from the warehouse (the asset pipe in the screens plan). Each tile's dashed data expander names the mart, route, and key fields feeding that zone, so reviewing a wireframe doubles as reviewing the API payload. The edge-agent dock (✦, bottom right) is reserved on every screen; on the Play Log it graduates into the layout as the session panel.
